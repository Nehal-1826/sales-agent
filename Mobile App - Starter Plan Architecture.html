API Endpoints Used

  • GET /api/workspace/notifications-inbox — Polling inbox (45s)
  • POST /api/workspace/notifications-inbox/{id}/read — Mark read
  • POST /api/workspace/notifications-inbox/read-all — Mark all read
  • POST /api/workspace/tools/placement — Placement test
  • POST /api/workspace/tools/spam-scan — Spam scan
  • POST /api/workspace/mailboxes/{id}/dns-check — DNS check
  • POST /api/workspace/reports/generate — Generate report
  • POST /api/workspace/payments/auto-pay — Toggle auto-pay
  • GET /api/workspace/billing/status — Billing status
  • GET /api/workspace/payments — Invoice list
